## Project: Voice-to-Text App

React-based web application that converts voice input into text using speech recognition.

### Features

- Record voice using microphone
- Convert speech to text
- Display transcribed text
- Show recording status

### Tech Stack

- React.js
- Components: MicButton, TranscriptionArea, RecordingStatus
